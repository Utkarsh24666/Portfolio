# UTKARSH CHADHA® — BEYOND THE SURFACE

An immersive, responsive portfolio built with React, Vite, Three.js and React Three Fiber. The city is assembled from original procedural geometry; no external 3D model downloads or licenses are required.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

Deploy the generated `dist/` directory to Vercel, Netlify, or GitHub Pages. Relative asset URLs support both root-domain and repository-subpath deployments. The `public/` directory retains the existing image, certificate, and résumé files.

The original static portfolio is preserved at [`index.legacy.html`](./index.legacy.html), with the original project images and documents alongside it.
