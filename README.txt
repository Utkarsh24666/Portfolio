UTKARSH CHADHA® — BEYOND THE SURFACE

This portfolio is a React, Vite, Three.js and React Three Fiber application.

To run locally:
1. Install Node.js.
2. Run `npm install`.
3. Run `npm run dev`.

To deploy, run `npm run build` and publish the generated `dist` directory.
The image, résumé and certificate URLs are retained in `public/`.

The original static portfolio is preserved as `index.legacy.html`.
See README.md for project details and commands.
